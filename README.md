# GridFill

MaskGIT-style grid filler for arbitrary boards. This is a minimal project skeleton demonstrating
masked token modeling with uniqueness constraints.

Features:
- Masked reconstruction training over 2D grids of 1..N unique numbers.
- Iterative decoding with dynamic vocabulary masking and Hungarian projection.
- FastAPI service for inference.

This repository contains only a lightweight implementation intended for unit testing
and demonstration purposes.
